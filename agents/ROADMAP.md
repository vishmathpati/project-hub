# Project Hub Roadmap

Source: mirrored from root `ROADMAP.md`.

## v0.1 Current

- Projects: auto-detect from Claude Code, Codex CLI, and filesystem.
- Skills: install/remove SKILL.md skills per project from a global library.
- Agents: manage Claude sub-agents per project.
- MCP: read and manage MCP servers across supported tool configs.

## Compatibility Expansion

- Support Claude Code, Claude Desktop, Codex CLI, and Codex Desktop explicitly.
- Add MCP health checks, auth detection, restart/reload guidance, duplicate/conflict reporting, and safe fixes.
- Add skill discovery by app availability and scope.
- Add project root/settings detection by tool.
- Restructure the UI around scan, explain, fix, verify.
