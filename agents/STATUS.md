> Last updated: 2026-05-25 · Codex

## Current State

Project Hub is a local macOS menu-bar app for scanning projects and managing AI coding tool configuration.

Implemented surfaces include:

- Projects: discovery from Claude Code state, Codex state/config, and filesystem roots.
- Skills: global skill library scan and per-project install/remove for Claude/Codex-style skill folders.
- Agents: Claude Code sub-agent management.
- MCP: global and project config display/import/copy/edit for several AI tools.
- Settings: app metadata, launch at login, and skill path reference.
