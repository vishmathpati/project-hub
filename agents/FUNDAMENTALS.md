# FUNDAMENTALS.md — Craft Rules
> Global. Read before any UI work. Same content on every project.
> Brand-specific values live in `DESIGN.md`.

## The 6 Levels

1. Space: use a consistent 4px scale.
2. Hierarchy: make primary, secondary, and tertiary information obvious.
3. Color foundation: separate background, surface, elevated surface, and border.
4. Typography: one family, few sizes, consistent line-height.
5. Depth: show hierarchy through surfaces, borders, and restrained shadows.
6. Decoration: last, earned, and rare.

## Required States

Every interactive surface should account for loading, empty, error, populated, and edge states.

## Forms And Fixes

- Preserve user input on errors.
- Explain what happened, why if knowable, and what to do next.
- Preview changes before writing files.
