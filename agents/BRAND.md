# agents/BRAND.md — Project Hub
> What every agent must know before touching this project.

## Product

- Name: Project Hub
- Domain: Local macOS developer tooling
- One sentence: A personal Mac menu-bar app that helps the user inspect and manage AI coding tool setup across local projects.

## User

- Who it's for: A power user managing multiple AI coding tools, project worktrees, skills, agents, rules, and MCP configurations on one Mac.
- Problem it solves: Local AI-tool setup is scattered across dotfiles, app configs, per-project folders, and hidden state; Project Hub gives that setup one visible, editable place.
- What it is NOT: A cloud dashboard, team admin product, agent marketplace, or replacement for the AI coding tools themselves.

## Personality

- Tone: Quiet, native, capable, precise.
- Values: Local-first control, reversibility, clarity over novelty, visible boundaries between read-only inspection and writes.
- Avoid: Marketing gloss, gamified productivity copy, vague AI promises, destructive automation without preview.

## Product Signals

- It should feel like a serious Mac utility: compact, scannable, fast, and comfortable inside repeated daily use.
- UI language should distinguish "detected", "installed", "writable", "unsupported", and "needs manual action" without drama.
- Empty states should help the user take the next practical step, not sell the product back to them.
