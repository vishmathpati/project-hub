# BRAND.md

## Product Identity

Project Hub is a quiet local control center for AI coding tool setup.

It should feel:

- precise
- trustworthy
- local-first
- practical
- calm under complexity

## What Not To Build

- Do not build a marketing-style landing page.
- Do not hide file paths or scope details when changing config.
- Do not use vague "everything is synced" language. Tool compatibility is scoped and specific.
- Do not make dangerous fixes one-click without preview.
