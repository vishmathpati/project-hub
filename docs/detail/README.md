# docs/detail/

Deep-dive documentation for features too complex for a single INDEX.md entry.

## Creation rule

Only create a file here when a feature's flow cannot be captured in the INDEX.md entry.
Examples of when to create: Live Mode active-project detection algorithm, multi-step profile copy flow.
Examples of when NOT to create: basic CRUD views, standard SwiftUI sheets.

When created, the INDEX.md entry links here: `→ docs/detail/feature-name.md`
